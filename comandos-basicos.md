# Comandos básicos de Git

## git init

Permite inicializar un nuevo repositorio Git en un directorio local. A partir de este comando, Git comienza a realizar el seguimiento de los cambios efectuados en los archivos del proyecto.

## git clone

Permite copiar un repositorio remoto en la computadora local, incluyendo su historial de commits y ramas.

## git status

Muestra el estado actual del repositorio, indicando archivos modificados, archivos preparados para commit y archivos sin seguimiento.

## git add

Agrega cambios al área de preparación (staging area) para que puedan incluirse en el próximo commit.

## git commit

Registra de manera permanente los cambios preparados en el repositorio local.

## git log

Muestra el historial de commits realizados en el repositorio.
